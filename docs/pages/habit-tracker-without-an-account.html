A habit tracker that doesn't want your email

Every habit app asks you to create an account first. You wanted to check a box, not onboard a service. So what happens if we delete the account entirely?

The sign-up tax

An account is not free. It costs you an email, a password you will forget, and a promise about what happens to your data when the company is acquired or shut down. In exchange you get sync, which is a real feature — and you get a service that can go away.

For a personal habit tracker, most people use exactly one machine, check the same six boxes every evening, and would be mildly annoyed to lose the history. That is a problem a file solves, not a server.

What "local" means here, precisely

Plan Card keeps everything in one file, plan_data.json, sitting next to plan_card.pyw. Your plans, the check-in history, the theme you picked, the window position — all of it. There is no network code in the repository at all, which is a claim you can verify by reading it.

The check-ins themselves are the only interesting data. Each plan row gets a stable id, and every click appends a date under that id, which is what makes a streak possible:

"打卡记录": {
  "a3f91b2c": ["2026-11-03", "2026-11-04", "2026-11-05", "2026-11-08"]
}

That is the whole database. From it the card computes a current streak, the number of check-ins today, and a 30-day completion rate.

What you give up

Honesty is more useful than a feature list, so here is the cost side:

ThingCloud appPlan Card
Same data on two computersAutomaticCopy the file yourself
Phone appYesNone
BackupsProvider's jobYour job — copy the JSON
Survives the company closingProbably notYes, it is a file
Sold or leaked to a third partyPossibleNothing to sell

If you use two machines daily, this design is wrong for you and you should use something that syncs. If you want a tool that still works in five years, a JSON file is a better bet than a startup.

Working around the missing sync

If you want sync anyway, you do not need the app to implement it:

  • Put the folder in OneDrive, iCloud Drive or Dropbox. It is one file; the sync client does not care what is in it.
  • Or commit it to a private git repository and pull on the other machine. JSON diffs badly, but for a personal tracker that rarely matters.
  • Or just copy it before you move. This is the honest answer for the 90% case.
