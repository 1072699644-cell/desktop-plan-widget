Open source sticky notes for Windows

There is no shortage of note apps. The problem is that almost none of them are desktop notes — they are browsers wearing a desktop icon, and you have to open one before you can see your own plan.

The options, and what each is really for

ToolWhat it isBest for
Sticky Notes
built into Windows		 A note window per note, tied to your Microsoft account for sync Jotting a phone number. Nobody's plans.
Joplin
open source		 A full note-taking system with sync, encryption and mobile apps Thousands of notes you need to search
Obsidian
free for personal use		 Local markdown knowledge base Connected, interlinked writing
Commercial desktop notes Polished always-on-top note cards, usually paid Naked notes you glance at
Plan Card
MIT, one Python file		 A frameless card on your wallpaper with four kinds of plans, check-ins and an automatic self-review Small structured plans you actually look at

Why "not Electron" is a real criterion

An Electron note app is 100–200 MB installed and 150–400 MB of RAM while idle, because it ships a browser. For a tool you keep open all day on a work laptop, that is not a detail — it is the difference between a widget and an application.

Plan Card is a 70 KB script using only the Python standard library, so it uses whatever Tk uses (tens of megabytes) and starts instantly. The trade is that it looks like a native Windows widget rather than a web page, and it has no plugin ecosystem, because there is no ecosystem — it is one file.

What Plan Card is not

Being clear about this saves everybody time:

  • Not a note app. It has no free-form notes, no images, no attachments, no markdown. Rows are short text and a state.
  • Not a task manager. No projects, no tags, no dependencies, no Gantt, no recurring rules beyond "daily".
  • Not a sync product. One JSON file on one machine. If you work on two computers, this will annoy you.
  • Not cross-platform. The frameless rounded translucent window is Win32 API; there is no macOS or Linux build.

If you need any of the above, Joplin or a real task manager is the right answer and you should use it. The point of this tool is the narrow middle: a small structured plan that you see without opening anything.

How to choose in one minute

  • You want many notes with search → Joplin.
  • You want linked writing → Obsidian.
  • You want a plain sticky note that syncs → Sticky Notes.
  • You want a few habits and goals visible on the desktop, with no account and no network → Plan Card.

Reading the source before you run it

The usual reason people look for open source is that they do not trust a random executable. The relevant promises here are checkable in a few minutes:

  • No network code: grep the repository for socket, urllib, requests.
  • No account: no login screen exists, so there is nothing to log in to.
  • No telemetry: no analytics endpoint, because there is no network code at all.
  • Data you can read: plan_data.json is plain JSON, not a database.
