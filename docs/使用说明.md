# 计划表 · 使用说明

按“第一次打开 → 日常怎么用 → 出了问题怎么办”的顺序写的完整手册。
英文版：[Usage.md](Usage.md) · 项目首页：[README](../README.md)

---

## 一、第一次打开

双击 **`plan_card.pyw`**。

- 第一次启动会**自动载入示例计划**，不是空的。随便改、随便删——它们只是示例
- 数据写在脚本旁边的 **`plan_data.json`**
- 真出问题时，**`plan_card.log`** 里会有完整的错误堆栈
- 想重来：删掉 `plan_data.json`，示例计划会重新出现

这张卡片**不是普通窗口**：没有标题栏、不在任务栏占位、始终沉在其它窗口下面。
**按住顶部区域拖动**可以移动它，位置会记住。

## 二、卡片上都有什么

```
┌──────────────────────────────────────────────────────┐
│ 计划表                          ⚙        ╭───╮       │ ← ⚙ 设置
│ 11月8日 周日 · 打卡 3/7 · 目标 0/9       │ 0 │       │ ← 环 = 目标进度
├──────────────────────────────────────────────────────┤
│ 自我总结   自动生成 · 点开查看                    ›  │ ← 点一下展开
├──────────────────────────────────────────────────────┤
│ ▪ 每日  ⌄ ─────────────────────────────────── 3/7    │ ← 点段名可收起
│   [已打卡] 早上 7:00 起床，读 30 页书       ✕  详情  │
│   [ 打卡 ] 每天走够 6000 步                 ✕  详情  │
│ ▪ 阶段  ⌄ ─────────────────────────────────── 0/6    │
│   高  60天 ○ 三个月内完成毕业论文初稿       ✕    0%  │
│ ▪ 长期  ⌄ ─────────────────────────────────── 0/3    │
│ ▪ 未来  ⌄ ─────────────────────────────────── 0/4    │
├──────────────────────────────────────────────────────┤
│ [每日 ▾]  添加一条计划，回车确认                 ＋  │ ← 永远固定在底部
└──────────────────────────────────────────────────────┘
```

每行右边那三个很淡的符号（`⇄` `›` `✕`）**只在鼠标移到该行时才亮起来**。
东西没少，只是平时安静。

## 三、加一条计划

1. 点**输入框左边的小胶囊**，选择新计划加到哪一段：`每日 → 阶段 → 长期 → 未来`
2. 在输入框写内容，按 **`回车`**（或点 `＋`）

卡片会自动变高，**输入框永远不会被内容挤掉**。

## 四、每日打卡

每日那一行左边只有一个按钮：

| 显示 | 含义 |
|---|---|
| **打卡**（深色） | 今天还没打 |
| **已打卡**（绿色） | 今天打了 |

- 点一下打卡，再点一下取消——**两种状态都会被记录**
- 行文字**永远不划横线**：每日是习惯，不是一次性任务
- 每天早上清单**重置**（勾选清零），但计划条目保留，第二天继续打卡

### 时间详情

点行尾的 **「详情」**：

```
早上 7:00 起床，读 30 页书
打卡 6 天 · 连续 3 天 · 近30天 71%
──────────────────────────────
11月7日 周六   ✓ 打卡
11月6日 周五   ✓ 打卡
11月5日 周四   · 未打卡
...
```

| 数字 | 含义 |
|---|---|
| **打卡 N 天** | 累计打过卡的天数 |
| **连续 N 天** | 从今天往前连着打了几天（今天还没打就从昨天数） |
| **近 30 天 %** | 最近 30 天里打卡的比例 |

显示最近 14 天，更早的仍然计入总数。
每条每日计划内部有**跨天不变的 ID**，所以每天早上重置之后，历史仍然挂在同一条上。

## 五、阶段目标与期限

阶段行的左边有一个小标签：

| 显示 | 含义 |
|---|---|
| `期限`（灰） | 还没设，点它去选 |
| `12天`（蓝） | 还剩 12 天 |
| `今天`（琥珀） | 今天到期 |
| `逾期3`（红） | 已经超期 3 天 |

点它弹出**月历**：

- `◀` `▶` 翻月
- 点某一天立即生效
- **今天** = 设成今天；**清除期限** = 删掉期限；`Esc` 关闭

## 六、长期与未来

- **长期** —— 持续进行的事，显示完成百分比，没有期限
- **未来** —— “以后想做”的暂存区，**完全不显示百分比**

顶部进度环**只统计阶段 + 长期**（这两个有百分比）；日期旁边的 `打卡 3/7` 是每日的打卡进度。

## 七、编辑、排序、换分类、删除

| 做什么 | 怎么做 |
|---|---|
| 改文字 | 在行上**双击** |
| 删除 | 点行尾 `✕` |
| 改重要性 | 点左边的 `高` / `中` / `低` |
| 排序 | 按住行上下拖 |
| 换分类 | 点 `⇄` 选目标段，**或者**把行直接拖到那一段里 |
| 子计划 | 点行尾 `›`，再点「＋ 添加细节」 |
| 完成子计划 | 点它前面的小圆圈 |
| 收起某段 | 点段名（状态会记住） |

单击行文字是勾选——它会先等 0.23 秒，所以双击编辑不会误勾两次。

## 八、自我总结

最顶上那块是**自动算出来的**，不用写。默认收起：

```
自我总结   自动生成 · 点开查看                    ›
```

点这一行任意位置展开：

```
自我总结   11月8日 周日 · 打卡完成 3/7，还差 4 条        ⌄
[日][周][月]
有记录天数 1/7     打卡次数 15
日均完成 43%       最长连续 1 天
阶段目标 0/6       长期目标 0/3
```

| 页签 | 统计内容 |
|---|---|
| **日** | 每日打卡 n/m、连续打卡、阶段 n/m、长期 n/m |
| **周 / 月** | 有记录天数、打卡次数、日均完成、最长连续、阶段/长期进度 |

「日均完成」是区间内**按条目加权**的平均完成率，不是“每天百分比的平均”。

## 九、设置（⚙）

点右上角齿轮。

| 项目 | 说明 |
|---|---|
| **名称** | 卡片标题，最多 20 字，**按回车生效** |
| **主题** | 5 套风格，点了立即换 |
| **语言** | `跟随系统` / `中文` / `English` |
| **透明度** | 30%–100%，拖动实时生效，松手保存 |

设置面板**本身是不透明的**，所以卡片调到 30% 也照样看得清。

### 五套主题

| 主题 | 配色 | 打卡按钮 | 段标识 |
|---|---|---|---|
| **可爱** | 淡粉、马卡龙四色 | 圆角药丸实心 | 圆点 |
| **极简** | 近白、全灰阶 | 1px 直角空心框 | 小方块 |
| **水墨** | 宣纸、楷体 | 文字 + 一道墨线 | 竖墨条 |
| **科技** | 深空、霓虹 | 双括号 `│打卡│` | 斜刻度 |
| **中式** | 乌木、国色、楷体 | 印章式描边框 | 菱形 |

换主题是**整卡重建**：配色、字体、按钮形状、段标识、勾选框线宽一起变，不是换个色号。

## 十、开机自启（可选）

本工具**不会**把自己加到开机项里。

1. `Win + R` → 输入 `shell:startup` → 回车
2. 把 `plan_card.pyw` 的**快捷方式**放进这个文件夹

> 不想看到黑色控制台窗口，快捷方式要用 `pythonw.exe`：
> `"C:\Program Files\Python39\pythonw.exe" "D:\路径\plan_card.pyw"`

## 十一、你的数据

| 文件 | 是什么 |
|---|---|
| `plan_data.json` | 全部计划、打卡记录、设置——**唯一需要备份的东西** |
| `plan_card.log` | 出错日志，只在真出问题时才写 |

全部本地运行，这个项目里没有一行联网代码。

换电脑：把 `plan_card.pyw`、`tools/` 和 `plan_data.json` 一起拷过去即可。

## 十二、常见问题

| 现象 | 处理 |
|---|---|
| 双击没反应 | 看 `plan_card.log`；确认 Python 版本 `python --version` ≥ 3.8 |
| 卡片看不见了 | 换过显示器可能跑到屏幕外：把 `plan_data.json` 里的 `"位置"` 改成 `[100, 100]` |
| 不想要示例计划 | 删掉 `plan_data.json`，重新建自己的 |
| 文字显示成方块 | 装一个中文字体，或在设置里把语言切成 English |
| 语言不对 | 设置 → 语言 → `中文` / `English` |
| 重启后不见了 | 它本来就不会自启，见第十节 |
| 卡片太大或太小 | 受 Windows 缩放比例影响，按 1080p / 100% 缩放设计 |
