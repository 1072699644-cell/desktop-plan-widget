# 使用说明 · 计划表

这是桌面计划表的完整说明书。
English version: [Usage.md](Usage.md)

---

## 一、第一次打开

双击 `plan_card.pyw`。第一次启动会**自动载入一组示例计划**（中文系统给中文，
其它系统给英文），你可以随便改、随便删。

- 数据文件：`plan_data.json`，就在脚本旁边
- 出错日志：`plan_card.log`（只有真出错才会写）
- 想重来：删掉 `plan_data.json`，示例会重新出现

这张卡片**不是普通窗口**：没有标题栏、不在任务栏占位、始终沉在其他窗口下面，
像壁纸挂件。按着标题栏可以拖动，位置会记住。

## 二、四段计划

| 段落 | 用途 | 有百分比吗 |
|---|---|---|
| **每日** | 今天要做的习惯，每天早上重置 | 没有（打卡制） |
| **阶段** | 有期限的目标 | 有 |
| **长期** | 长期要做的事 | 有 |
| **未来** | 以后想做的清单 | 没有 |

四段**同时显示**。点段名（或它后面的 `⌄`）可以**收起**这一段，收起状态会记住。

---

## 三、每日打卡

每日那一行左边只有一个按钮：

- **打卡**（深色）＝ 今天还没打
- **已打卡**（绿色）＝ 今天打了

点一下打卡，再点一下取消（记录同步改）。**文字不会划横线**——每日是习惯，
不是任务。

**时间详情**：点行尾的「详情」。

```
每天早上读书
打卡 6 天 · 连续 3 天 · 近30天 71%
────────────────────────
11月7日 周六   ✓ 打卡
11月6日 周五   ✓ 打卡
11月5日 周四   · 未打卡
...
```

- **打卡 N 天**：累计打过卡的天数
- **连续 N 天**：从今天往前数连着打了几天（今天没打就从昨天数）
- **近 30 天 %**：最近 30 天的打卡比例
- 显示最近 14 天，更早的只计数

每条每日计划内部都有一个**跨天不变的 ID**，所以每天清单重置之后，记录仍然挂在
同一条习惯上，不会断。

---

## 四、期限（阶段计划）

阶段那一行左边有一个小标签：

| 显示 | 含义 |
|---|---|
| `期限`（灰） | 还没设，点它去选 |
| `12天`（蓝） | 还剩 12 天 |
| `今天`（琥珀） | 今天到期 |
| `逾期3`（红） | 已经超期 3 天 |

点它弹出**月历**：`◀ ▶` 翻月，点某一天立即生效，底部有 **今天** / **清除期限**，
`Esc` 取消。

## 五、编辑

| 做什么 | 怎么做 |
|---|---|
| 改文字 | 在行上**双击** |
| 删除 | 点行尾 `✕`（鼠标移上去才出现） |
| 改重要性 | 点左边的 `高` / `中` / `低` |
| 排序 | 按住行**上下拖** |
| 换分类 | 点 `⇄` 选，或把行**拖到别的段** |
| 加子计划 | 点行尾 `›`，再点「＋ 添加细节」 |
| 完成子计划 | 点它前面的小圆圈 |

单击行文字＝勾选/打卡（延迟 0.23 秒执行，这样双击编辑不会误勾两次）。

## 六、自我总结（自动生成）

最顶上第一块就是「自我总结」，默认只有一行：

```
自我总结   自动生成 · 点开查看          ›
```

点这一行任意位置展开：

```
自我总结   11月8日 周日 · 打卡完成 3/7，还差 4 条        ⌄
[日][周][月]
有记录天数 1/7     打卡次数 15
日均完成 43%       最长连续 1 天
阶段目标 0/6       长期目标 0/3
```

**完全自动**，不用写。左上角 **日 / 周 / 月** 切换统计口径。

## 七、设置（⚙）

点右上角齿轮：

| 项目 | 说明 |
|---|---|
| **名称** | 卡片标题，改完按 `回车` 生效 |
| **主题** | 5 套风格，点了立即换 |
| **语言** | 跟随系统 / 中文 / English |
| **透明度** | 30%–100%，松手即保存 |

四项都存在 `plan_data.json` 里，重装重启都记得。

### 五套主题

| 主题 | 观感 | 打卡按钮 | 段标识 |
|---|---|---|---|
| **可爱** | 淡粉底、马卡龙四色 | 圆角实心药丸 | 圆点 |
| **极简** | 近白底、全灰阶 | 1px 直角空心框 | 小方块 |
| **水墨** | 宣纸底、楷体 | 文字 + 一道墨线 | 竖墨条 |
| **科技** | 深空黑、霓虹 | 双括号 `│打卡│` | 斜刻度 |
| **中式** | 乌木底、国色、楷体 | 印章式描边框 | 菱形 |

换主题是**整卡重建**：配色、字体、按钮形状、段标识、勾选框线宽一起变。

## 八、开机自启（可选）

本工具不会自己装到开机项里。想开机自动出现：

1. 按 `Win + R`，输入 `shell:startup`，回车
2. 把 `plan_card.pyw` 的**快捷方式**放进这个文件夹

> 不想看到黑色控制台窗口的话，快捷方式要用 `pythonw.exe`：
> `"C:\Program Files\Python39\pythonw.exe" "D:\路径\plan_card.pyw"`

## 九、常见问题

| 现象 | 处理 |
|---|---|
| 双击没反应 | 看脚本旁边的 `plan_card.log` |
| 卡片看不见了 | 可能换过显示器跑到屏幕外：把 `plan_data.json` 里 `"位置"` 改成 `[100, 100]` |
| 不想要示例计划 | 删掉 `plan_data.json`，重新建自己的 |
| 文字显示成方块 | 装一个中文字体，或在设置里切成 English |
| 语言不对 | 设置 → 语言 → 中文 / English |
