# Architecture · 项目说明

How the Plan Card is built. 中文为主，关键处给英文。

```
plan-card/
├─ plan_card.pyw        # 卡片本体（窗口、布局、交互、主题、i18n 装配）
├─ tools/
│   ├─ plan.py          # 数据层：读写、四段、打卡记录、自动总结、示例播种
│   └─ i18n.py          # 中英词表 + 语言检测 + 本地化日期格式
├─ sample/
│   ├─ plan_data.json      # 中文示例
│   └─ plan_data.en.json   # 英文示例
└─ docs/
```

## 1. 为什么是 Tkinter + Win32

目标是一张**贴着桌面、没有边框、能透出壁纸**的卡片。

| 需求 | 做法 |
|---|---|
| 无边框 | `root.overrideredirect(True)` |
| 圆角 | `CreateRoundRectRgn` + `SetWindowRgn`（Win32） |
| 半透明 | `root.attributes("-alpha", v)`（分层窗口） |
| 沉在其他窗口下面 | 去掉 `WS_EX_TOPMOST`，保持普通层级 |
| 拖动 | 自己绑 `<ButtonPress-1>` / `<B1-Motion>` 移动窗口坐标 |

没有引入 Qt / Electron：整个程序 **零第三方依赖**，拷两个文件就能跑。

## 2. 布局与自适应高度

卡片高度不是写死的，而是**按内容迭代收敛**：

```python
for _ in range(4):                 # 宽度定下来 → 文字换行 → 高度才准
    bh = self.bottom.winfo_reqheight()
    need = 61 + self.inner.winfo_reqheight() + bh + 22
    floor = 61 + bh + 22 + 34      # 至少留出「表头 + 输入框 + 一行」
    avail = max(220, scr_h - taskbar - py)   # 最多长到屏幕底部
    h2 = max(150, floor, min(avail, need))
```

要点：

- **输入框永远可见**：`bottom` 先 `pack(side="bottom")`，再让滚动区 `expand`
- **屏幕底部放不下就整体上移**，保证整卡在屏幕内
- 只有内容超过一屏时才出现细滚动条（3px，鼠标滚动时按比例显示位置）

### 行内对齐

每行左侧是一个**固定宽度栏位**（中文 86px / 英文 108px），
打卡按钮、重要性、期限、勾选框都放进这个栏位并**靠右贴齐**，
因此四段的正文左边缘完全对齐，扫读时不会跳。

实现上用了一个可伸缩的空 Frame 把左侧标签推到右边：

```python
col = tk.Frame(line, width=colw, height=22)
col.pack_propagate(False)
tk.Frame(col, bg=pbg).pack(side="left", fill="both", expand=True)  # 弹簧
```

## 3. 数据结构

`plan_data.json`（**键名保持中文，老数据不用迁移**）：

```jsonc
{
  "位置": [56, 300],          // 窗口坐标
  "名称": "",                  // 自定义标题（空=用默认，跟随语言）
  "语言": "auto",              // auto / zh / en
  "主题": "浣纱",              // 主题名（中文键）
  "透明度": 0.9,
  "总结页": "日",              // 自我总结记住的页签
  "折叠": ["阶段"],            // 收起的段
  "新计划归入": "每日",         // 底部输入框的目标段
  "天": {
    "2026-11-08": { "条目": [
      { "文字": "…", "完成": false, "重要": "高",
        "细节": [{ "文字": "…", "完成": false }],
        "id": "a1b2c3d4"            // 每日计划才有：跨天不变的 ID
      }
    ]}
  },
  "阶段计划": { "条目": [ { …, "结束日期": "2026-12-08" } ] },
  "长期计划": { "条目": [ … ] },
  "未来计划": { "条目": [ … ] },
  "打卡记录": { "a1b2c3d4": { "2026-11-07": true, "2026-11-08": false } }
}
```

四条设计取舍：

1. **键名用中文**——原作者的数据文件不必迁移，开源版的界面才翻译
2. **每日按天存**，其它三段存在独立的键里，互不影响
3. **每日计划带 `id`**——清单每天重置，但记录挂在同一条习惯上
4. **打卡记录独立存**——按 `id → 日期 → bool`，与清单解耦

## 4. 打卡机制

```
点击打卡 → 改 完成 → record_day() 写 打卡记录[id][今天] = is_done
每天早上 → carry_over() 把昨天整张清单复制过来，完成状态清零（子计划也清零）
```

- **为什么要复制而不是"顺延未完成"**：习惯类计划如果只在没做完时出现，
  打完一次就从清单里消失了；打卡制要求"每天都重新打卡"
- **为什么 ID 要跨天不变**：连续天数、近 30 天比例都靠 `打卡记录` 聚合，
  没有稳定 ID 就串不起来
- 有子计划的条目：子计划全部完成才算这条打卡

## 5. 自动总结算法

```python
_day_stats(d, day)      # 某天 (完成数, 总数)
_streak_upto(d, day)    # 从某天往前数，连续「当天全打完」的天数
_range_days(...)        # 周 / 月的日期区间
```

| 周期 | 统计项 |
|---|---|
| 日 | 每日打卡 n/m、连续打卡、阶段 n/m、长期 n/m |
| 周 / 月 | 有记录天数、打卡次数、日均完成、最长连续、阶段/长期 |

「日均完成」= 区间内所有天的 `完成数 ÷ 总数` 的加权平均（不是天数的平均），
这样条目多的那天权重更大，更接近真实体感。

## 6. 主题系统

主题不只是配色，还带**形态参数**：

```python
"水墨": dict(bg="#f2eee3", fg="#24211c", acc="#8c2f24", ok="#4b7b5a",
            fam="楷体", btn=("ink", 0), dot="bar", chk=1.6,
            sec=["#3a352e", "#4f6360", "#7a5c44", "#5f7052"])
```

| 参数 | 作用 |
|---|---|
| `bg/fg/sub/dim/acc/ok` | 主色板 |
| `sec` | 四段分类色 |
| `fam` | 标题/段名/按钮字体 |
| `btn` | 按钮形态：`fill` 圆角实心 / `outline` 直角描边 / `ink` 墨线 / `bracket` 双括号 / `seal` 印章 |
| `dot` | 段标识：`circle` / `square` / `bar` / `slash` / `diamond` |
| `chk` | 勾选框描边宽度 |

### 明暗自适应推导

浅色主题和深色主题的「次级色」方向相反，所以不是简单加白：

```python
def _shift(bg, t):
    """朝对比方向偏移：深底更亮，浅底更暗。"""
    return _dark(bg, t) if _is_light(bg) else _light(bg, t)
```

悬停底色、分割线、输入框、小胶囊、行尾图标的淡色全部由 `bg` 推导，
所以只要给一个底色 + 强调色，整套界面就是协调的。

### 按钮与标识用 Canvas 画

Tk 的 `Label` 不能单独设圆角，所以打卡按钮、段标识、勾选框都是 `Canvas`：

```python
def _rr(cv, x0, y0, x1, y1, r, **kw):     # 圆角矩形（r=0 即直角）
    if r <= 0:
        return cv.create_rectangle(x0, y0, x1, y1, **kw)
    pts = [x0+r,y0, x1-r,y0, x1,y0, x1,y0+r, x1,y1-r, x1,y1,
           x1-r,y1, x0+r,y1, x0,y1, x0,y1-r, x0,y0+r, x0,y0]
    return cv.create_polygon(pts, smooth=True, **kw)
```

## 7. 国际化（i18n）

```python
L("打卡")   # 中文原样返回，英文查表 → "Check in"
```

- **用中文原文当 key**，界面代码只包一层 `L(...)`，不会漏翻，也不用维护另一套 key
- 语言：`auto`（跟随系统）/ `zh` / `en`，存在数据文件里
- **必须在读数据之前确定语言**：首次运行播种示例时要按语言选中文或英文示例
- 英文下额外调整：左侧栏位 86→108px、按钮 56→78px、日期格式改 `Sun, Nov 8`、
  数字字体（科技主题）用 Consolas

## 8. 已知限制

- **只支持 Windows**：圆角裁剪、分层窗口都依赖 Win32 API
- **Tk 无法给任意控件圆角**：只有整窗裁剪 + Canvas 自绘两条路
- **字体依赖系统**：苹方 / 楷体在部分系统上缺失时会回退
- 数据文件键名是中文（有意为之，见第 3 节）
